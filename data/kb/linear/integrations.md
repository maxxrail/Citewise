# Linear integrations and importers

## Integrations

Linear's integrations include GitHub, GitLab, Slack, Figma, Sentry, Zendesk, Intercom, Notion, Discord, Zapier, Loom, Miro and Salesforce. Coding agents such as Cursor, GitHub Copilot, Codex and Devin connect to Linear, and AI clients including ChatGPT and Claude connect through MCP.

## Importing from Jira

Linear has a Jira integration for moving work from Jira to Linear. Import and export are included on every plan.
